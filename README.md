# Mengyue Huang — Portfolio

Personal portfolio and project archive for data science, machine learning, analytics, and full-stack data products.

## Run locally

```powershell
bundle exec jekyll serve --port 4008
```

Then open [http://127.0.0.1:4008/](http://127.0.0.1:4008/).

## Content

- `pages/` — homepage, project archive, journal, and supporting pages
- `_projects/` — project case studies
- `_posts/` — journal posts
- `python_notebooks/` — project analysis source files
- `assets/` — styles, scripts, images, interactive chart specifications, and downloadable data

The site is published through GitHub Pages at [mengyuehuang.github.io](https://mengyuehuang.github.io/).
